# Employee Attrition Analysis

## Objective

Analyze employee attrition patterns and identify factors that contribute to employee turnover.

## Tools Used

- Python
- Pandas
- Seaborn
- Matplotlib

## Key Findings

- Attrition rate is approximately 16%.
- Sales has the highest attrition rate.
- Overtime is strongly associated with employee attrition.
- Employees who leave tend to be younger and earn less.

## Business Recommendations

- Review overtime policies.
- Improve retention efforts in Sales.
- Review compensation strategies.
